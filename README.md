# Сложно сосредоточиться

Адаптивная страница о концентрации внимания с мобильной вёрсткой, галереей изображений и переключением между светлой, тёмной и системной темами.

## Запуск

Откройте `index.html` в браузере. Сторонние зависимости не нужны.

## Структура

- `styles/` — общие стили, адаптивная сетка и темы;
- `fonts/` — шрифт IBM Plex Mono;
- `images/` — изображения страницы и иконки;
- `scripts/script.js` — переключатель темы.
